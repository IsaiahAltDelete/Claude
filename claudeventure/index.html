ClaudeVenture

A shop-builder you look down on from the corner. Guests come in, the crew run orders out, and everything you make goes back into the machines. Every model on screen — the stalls, the food, the guests, the fifty-odd things you can put on — is generated from code by the voxel maker in /voxel when the page loads. There are no sprites and no model files in this folder.

  • 5 shops
  • 12 stalls
  • 51 garments
  • drawn with WebGL2
  • no dependencies
  • no build step

How to play

Machines make food on a timer. Crew carry it to whoever is waiting at the counter. Guests eat, pay, and leave the money on the floor — the till sweeps it up on its own, but sweeping it by hand pays a fifth more. Tap a machine to rush it. Tap a gift box to open it.

Spend everything, always. Upgrading a machine raises what its dish is worth faster than it raises the price of the next level, so the only question is which one to feed. Every tenth level changes how a machine looks, and the twenty-fourth changes it again. When the lifetime bar fills, move on: the machines start again at level one and the new shop pays two hundred and fifty times better.

Everything here is a recipe

A voxel model in this repository is a function handed an empty grid — see the maker for the whole story. ClaudeVenture is what that is for. The twelve stalls are one recipe each, run at three tiers; the fifty-one garments are one function each, drawn onto whatever body is wearing them; the guests are seeded, so guest four is always guest four. Nothing is loaded from disk, because there is nothing on disk to load: 

claudeventure/scripts/01-props.js   62 models — stalls, dishes, fittings, the room
claudeventure/scripts/02-people.js  51 garments and the body they hang off
claudeventure/scripts/03-stage.js   the isometric renderer, WebGL2 and CPU
claudeventure/scripts/04-content.js the shops, the curves, the drop tables
claudeventure/scripts/05-game.js    the simulation — 20 Hz, fixed step
claudeventure/scripts/06-scene.js   game state -> a list of things to draw
claudeventure/scripts/07-hud.js     the interface
claudeventure/scripts/08-boot.js    wiring, saving, and the loop

The stage is a second renderer over the maker's own meshes: VOX.mesh still does the greedy merge and bakes the ambient occlusion, and VOX.View still owns the light rig, so a burger here is lit exactly as it is in the catalogue. What is added is per-draw placement, which is what lets one uploaded mesh be thirty guests. Where WebGL2 is missing, every model is baked once to a sprite by the same software rasteriser that renders the sheets in voxel/assets, and the frame becomes a depth-sorted stack of images — which is how isometric games were drawn before anyone had a GPU.

Your save

Kept in this browser under isaiart.claudeventure and nowhere else. Nothing is uploaded, there is no account, and closing the tab is fine — shut shops keep earning at 40% for up to eight hours. Start over in the Stats tab wipes it.
